# AFKFarmUtils

**AFKFarmUtils** is a client fabric mod designed to automate your farm without the need for player input.
Currently, it only supports **MOB FARMS**. <br>
Please make sure that you are allowed to use this mod on the server you are playing on.

## 🧱 Features

- [ ] Auto Attack
- [ ] Auto feeding
- [ ] Panic Features (*More on that soon*)
- [ ] Perma-Shift (Sneak)

> **Note**: More features and documentation will be added soon.
